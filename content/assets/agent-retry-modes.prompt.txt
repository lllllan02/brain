Use case: infographic-diagram.
Asset type: 中文知识笔记中的辅助解释图。
Primary request: 比较同一个只读订单查询遇到两种失败时，下一次尝试的输入是否改变，以及程序与模型分别做什么。只比较两条路径，不绘制完整重试控制循环。

Reference images:
- /Users/lllllan/lllllan02/horizon/.agents/skills/excalidraw-diagram/assets/diagram-style-reference.png：仅风格参考。迁移文档折角、对象造型、轮廓、小面积淡彩、中文层级与视觉分量；不要复制工具注册表内容、布局或字段。

Style:
克制的二维技术编辑插画，白底、充足留白、规整易读的中文字体、中等偏细的统一轮廓与柔和圆角。实际对象有不同造型：请求用折角纸张，等待用小钟，模型用带三个相连节点的小型中性轮廓，服务用简化服务器与结果票据。少量内部结构帮助理解。不要把各阶段画成同样的文字方框。无机器人、发光、高光、渐变、厚重阴影、手写标题、笔刷底色、装饰徽章、口号或页尾总结。
Palette: #ffffff 画布，#374151 轮廓与正文，#64748b 次要标签，#a8b3c2 轻分隔；#416788 与 #eaf0f7 表示保留不变的请求；#b66a43 与 #fbf0e6 仅强调错误字段和修改后的字段。不要按行铺大块色底。
Aspect: 横向约 3:2，清楚可读、主体较大，紧凑但不拥挤。

Objects and relationships:
左上适度大小标题「重发与修正后再试」，次标题「示意：同一只读查询的两种失败」。
画面分两条水平路径，每条都从左到右：失败的尝试 → 处理方式 → 下一次尝试 → 执行与检查。
上排左侧请求纸张标题 query_order，字段 order_id: A17，纸张下方有服务响应短标签「暂时断连」。指向中间小钟图形，标签「程序等待」。再指向第二张请求纸张，完全相同的 query_order 和 order_id: A17；纸张顶部或旁边标「输入不变」。最右为小服务器及返回票据，标签「执行并检查」。
下排左侧请求纸张标题 query_order，字段 id: A17，将 id 字段用淡橙强调；纸张下方为校验器反馈票据「缺少 order_id」。箭头将该反馈送向中间的模型节点，标签「模型修正」。再指向第二张请求纸张，标题仍是 query_order，字段变为 order_id: A17，将 order_id 字段用淡橙强调；纸张旁标「输入已修正」。最右同样是小服务器及返回票据，标签「校验后执行并检查」。
每排左侧就近小标签分别为「原样重发」「修正后再试」。恢复后的两张请求位置对齐，让相同与变化可直接对照。

Semantic invariants:
上排两张请求的工具名、字段名和值完全相同；下排只把错误字段 id 改为 order_id，值 A17 与工具名 query_order 保持不变。错误反馈传给模型，模型生成修正后的参数，程序执行查询。下排的首次调用在参数校验时失败。两行是独立的假设情形，不是同一次运行的连续步骤。下一次尝试不保证成功，返回票据不画成功对勾，不写「成功」。本图不展示预算、重试循环和中断恢复，这些由正文解释；不要添加不必要说明面板。

Composition:
两行留出明显间距，以轻细水平分隔区分。只使用必要的水平连接，标明箭头方向，避免交叉、折返、长绕线。把反馈票据贴近错误请求，清楚连接到模型。图形对象、状态变化和字段对比承担解释，不添加段落文字。
