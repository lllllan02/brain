Use case: infographic-diagram.
Asset type: 中文知识笔记中的辅助解释图，生成一张横向插画。
Primary request: 展示 Plan-and-Execute 如何把整体计划与单步执行分开。用一个假设的产品比较任务，展示已列出三步计划、当前只执行第一步收集资料的时刻；不是全部任务已完成的流程图。

Reference images:
- /Users/lllllan/lllllan02/horizon/.agents/skills/excalidraw-diagram/assets/diagram-style-reference.png：仅风格参考。迁移对象造型、细轮廓、小面积淡彩、规整中文和留白，不复制工具注册表的内容与布局。

Style:
克制的二维技术编辑插画，纯白底。计划是有夹子、纸边和清单行的计划纸；工具是带放大镜的小型搜索窗；资料是有折角与内部文字线的文档；不把所有对象都画成同样的方框。深灰蓝、中等偏细轮廓，浅色仅局部填充，规整易读中文，适度标题。不使用机器人、脑球、齿轮、大色块、粗黑描边、立体平台、渐变、重阴影或口号。
Palette: #ffffff 白底；#374151 文字；#416788 计划与资料轮廓；#eaf0f7 资料局部浅蓝；#b66a43 当前步骤与调用箭头；#fbf0e6 当前清单行浅橙；#a8b3c2 次要细节。
Aspect: 横向约 16:9，中文标签在正文缩放时仍可读。

Objects and relationships:
1. 左上适度标题「整体计划与单步执行」，下方小字「假设任务：比较 A、B 两款产品并给出建议」。
2. 主体从左到右三个区域，区域不加大外框。
3. 左侧标题「规划器」，下面一份夹板计划纸，纸内三行「收集资料」「比较差异」「形成建议」。第一行有橙色当前指针与小字「当前」，后两行用灰蓝色表示尚未执行，不打完成勾。
4. 中间标题「执行器」，从左侧第一行拉一条橙色水平箭头到中间，箭头上标「当前步骤」。中间上方短标签「收集资料」，下面两个纵向排列的小搜索窗口，分别是「查询 A 的资料」「查询 B 的资料」，各有放大镜造型。查询按需由执行器完成，不表示只有一次工具调用，也不暗示固定并发。
5. 右侧标题「单步结果」，两条短的橙色箭头各从对应搜索窗口到对应文档：上方折角文档「A 的资料」，下方折角文档「B 的资料」，文档有少量灰蓝文字线；这两份是收集步骤的产物。两份文档紧邻并用轻微叠放表达为一组资料，不添加最终报告或全任务完成标志。
6. 计划纸下方仅放一条短注「完成当前步骤后，继续后续计划」。它说明推进，不画复杂回环，不引入重规划。

Semantic invariants:
整体计划先形成，执行器接收当前子目标；当前只收集资料，比较与建议尚未执行。A 查询对应 A 资料，B 查询对应 B 资料，不能交叉。右侧资料只表示单步成果，不表示整个用户任务完成。没有反馈修改计划的分支；不加入费用、性能和适用场景面板。

Composition:
左侧计划约占 32%，中间执行约占 34%，右侧结果约占 24%，余下留白。主要对象的中心高度一致；两个搜索窗口与对应资料上下对齐。标题远小于参考图中的大标题，主体占主要面积。箭头短、落点明确，不穿过文字或对象内部。不把文字列表机械排成多张说明卡片。
