Use case: infographic-diagram.
Asset type: 中文知识笔记中的辅助解释图。
Primary request: 展示整个重试机制怎样将失败记录送入判断层，依据失败原因选择等待重试、先修正或停止；展示有限重试、指数退避、发送前复核、成功退出与再次失败后重新判断。主体是入口、判断与分流机制，不是两个案例的对比。

Reference images:
- /Users/lllllan/lllllan02/horizon/.agents/skills/excalidraw-diagram/assets/diagram-style-reference.png：仅风格参考。借鉴文档、目录、票据的形象化造型、细轮廓、小面积淡彩和规整中文。禁止复制其工具注册表的内容和布局。

Style:
克制的二维技术编辑插画。白底、充分留白、低饱和色、中等偏细的轮廓、柔和圆角，中文清楚易读。请求与错误用折角票据，判断层用有输入口和三个实际分流出口的规则档案夹，等待用小钟和逐渐增长的间隔刻度，修正用字段改写纸张，发送前检查用可开闭的闸口与小额度条，再次执行用简化服务器与结果票据，停止用收纳失败记录的托盘。图形与连接承担解释，不能只用同样的步骤方框堆文字。
Palette: #ffffff 画布，#374151 主要轮廓和文字，#64748b 次要文字，#a8b3c2 轻边界；灰蓝 #416788 / #eaf0f7 为可再次尝试的路径，暖橙 #b66a43 / #fbf0e6 为需先修正的路径，停止路径用中性深灰。不要把每个分支画成大块彩色背景。
Aspect: 宽幅约 16:10，分支与返回线有充足空间，主体文字足够大，标题适度。

Objects and relationships:
从左到右是「失败记录」→「重试判断层」→分流处理→「发送前复核」→「再次执行」→「检查结果」。各节点是实际对象的简化插画，避免全部相同的矩形。
左边画三张错开的小票据，共同进入判断层，票据分别写「暂时断连」「参数缺失」「不支持操作」。这是示意失败类型，不是必须依次发生的三个事件。左侧群组小标题「失败记录」。
画面中央偏左的判断层是视觉主体，类似带三行规则的路由档案夹，标题「重试判断层」。三行分别有明确出口，规则短语为：
上行「暂时故障，原样再试有望恢复」；蓝色出口连接右上方等待对象。
中行「输入或条件有误，需先修正」；橙色出口连接右中方修正对象。
下行「不可恢复，或安全性未确认」；灰色出口连接下方停止托盘。
等待对象包含小钟与逐渐拉大的三段间隔刻度，标签「等待后重试」「有限次数」「有上限的指数退避 + 抖动」「遵循服务端等待提示」。不写任何固定秒数，不把退避画成无上限增长。
修正对象是字段纸张上的 id → order_id 改写，仅为示意，标题「先修正」，小标签「模型修正参数或输出」「程序修复前置条件」。修正出口分成「已修复」和「无法修复」：已修复进入发送前复核，无法修复进入停止托盘。
等待后重试和已修复两条路径汇入同一个「发送前复核」闸口。闸口内部有小额度条，并写「安全性 · 次数 · 总期限 · 费用 · 取消」。闸口通过方向标「允许」，连接「再次执行」服务器，再连接「检查结果」票据。
闸口未通过的方向标「不允许」，连接同一个停止托盘。闸口应表达运行级预算，不只是本层次数。
检查结果右侧出口标「通过」，到小型完成出口「继续任务」。检查结果上方出口标「再次失败」，用一条清楚的外围返回线回到重试判断层的输入端，准确标「重新判断」，不能回到等待对象或跳过判断。
停止托盘是可达的真实出口，标题「停止自动尝试」，附小票据「返回原因」，近旁短标签「结果未知先核查」。不可恢复、无法修复、复核不允许三条路径均准确到达它。安全性未确认时是停止自动重发并核查，不得画成已经确认永久失败。

Semantic invariants:
入口处失败类型只提供判断依据，不能不加判断直接执行。暂时故障重试后可能成功，绝不保证成功。只有已修复的输入才能从修正路径进入发送前复核，无法修复必须停止。等待与修正都受总期限与取消约束，发送前还要检查安全性、次数与费用。指数退避有上限并可加入随机抖动，服务端等待提示也影响等待；不能靠无穷循环等待绕过预算。失败返回判断层，每轮可能改走不同分支。写入超时结果未知时停止自动重发先核查；不画成普通断连即能重发。通过检查才继续任务。

Composition:
优先让判断档案夹与实际分流出口占据视觉中心；右侧上方是等待区、中方是修正区，两者向同一个复核闸口汇合，右端是执行、结果检查与正常出口，下方是停止托盘。布局表达的是一股失败记录进入筛选后分流，禁止做两排案例前后对比。用简短标签标记分支条件，主线按从左到右阅读；停止分支下行，失败返回线在画面顶部留白处绕回判断输入端。尽量用直线和少量直角，不交叉穿过文字与对象；返回线须有明确方向和落点，不能为了直线省略循环或出口。无页尾总结、无额外说明面板或装饰图形。

Validation priorities:
