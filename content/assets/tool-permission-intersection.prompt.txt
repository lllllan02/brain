Use case: infographic-diagram.
Asset type: 中文知识笔记的解释插画，约 16:9 横向画幅，文字清晰，内容很少。
Primary request: 生成一张澄清“用户权限与 Agent 当前授权必须同时成立”的交集图。重点是两个范围重叠，只有重叠部分同时满足两层授权，单侧允许仍然不够。图只解释这一关系。

Reference image: /Users/lllllan/lllllan02/horizon/.agents/skills/excalidraw-diagram/assets/diagram-style-reference.png — 仅风格参考，借鉴白底、小面积淡彩、清楚灰蓝细轮廓、规整中文、文件对象造型。不复制订单业务、原有工具注册表内容和布局。
Style: 项目默认的克制二维技术编辑插画。白底留白，中等偏细的统一轮廓，适度圆角，深灰字 #374151，次要文字 #64748b。左范围灰蓝 #416788 / #eaf0f7，右范围低饱和暖橙 #b66a43 / #fbf0e6，交集突出灰蓝边缘与略深浅填充，避免多彩。不要装饰、3D、机器人、厚阴影或手写字体。

Composition:
- 顶部只有适度标题“两层授权必须同时成立”，右侧或标题下面极小“示意”。
- 中央两个足够大的水平相交椭圆，左椭圆范围标“用户权限”，右椭圆范围标“Agent 当前授权”。形状轮廓完整，重叠区域占约四成，保证中心文件与文字完全在交集内，边缘留足空白。
- 左边独占区域放一张带折角文件，文件写“读取 A”；旁边简短注“用户有权”“未获 Agent 授权”，两个条件在同一处。该文件完全在左范围里且明确在右范围外，灰色处理。
- 中间交集里只放一张形态相同的文件，写“读取 B”，灰蓝强调，文件附近写“双方均允许”。这张文件完整落在两个椭圆共同范围内。交集下方有与交集相连的很短指示线，标签“可操作范围”。
- 右边独占区域放相同文件，写“读取 C”；旁边注“Agent 获授权”“用户无权”，灰色处理。该文件完全在右范围里且明确在左范围外。
- 这三个文件用 A/B/C 指代抽象对象，不引入订单、财务、邮箱等具体业务，不画额外资源清单。
- 两个椭圆下方、居中一行短公式：“用户权限 ∩ Agent 当前授权 = 可操作范围”。∩ 必须是真正交集符号，不是并集，不是加号。
- 再下一行小号条件注：“实际执行仍须满足系统限制与确认要求”。此注必要但视觉次要。
- 不出现放行箭头、批准印章或成功勾号，避免把“可操作范围”误解为无需确认立即执行。也不在文件外再画结果复制。图的重点是空间归属与交集，不是处理流程。
