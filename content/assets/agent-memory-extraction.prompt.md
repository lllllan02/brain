Use case: infographic-diagram.
Asset type: 中文知识笔记中的辅助解释图，最终配合《Agent 记忆写入》的精简正文。
Primary request: 通过同一句用户原话的两部分分流，解释长期约束应提取为有范围和来源的记忆，本次要求只用于当前任务。以具体内容体现筛选，不画抽象流程框。

Reference images:
- /Users/lllllan/lllllan02/horizon/.agents/skills/excalidraw-diagram/assets/diagram-style-reference.png：仅风格参考。迁移二维对象造型、柔和轮廓、小面积淡彩、规整中文和适中的文字分量，不复制工具注册表业务或布局。

Style: 克制的二维技术编辑插画，白底与充足留白。纸张有折角、记录有字段分隔、便笺有轻微折边；对象造型清楚但不复杂。统一中等偏细轮廓，不用粗黑线、机器人、脑球、3D、发光、厚重阴影、手写标题、装饰框、页尾口号或概述面板。
Palette: 深灰 #374151 为正文，灰蓝 #416788 及浅蓝 #eaf0f7 表示被提取的长期约束；灰色 #64748b 与 #f8fafc 表示当前要求。少量暖米色 #faf5e9 用于纸张页签。
Aspect: 横向约 3:2，构图紧凑；正常笔记阅读宽度下文字仍清楚。标题适中，不占据大块空间。

Objects and relationships:
- 左侧是一张对话纸，标注「用户原话」。纸上有两段分离的原话：上段「项目甲今后的示例都用 Go」，下段「这次回答简短一点」。上段局部浅蓝，下段局部浅灰，不把整页涂成色块。
- 从上段右边缘出发一条灰蓝箭头，向右进入上方的折角记录纸。箭头旁标「以后仍适用」。记录纸标题「长期记忆」，内部三个字段逐行写「范围：项目甲的示例」「默认语言：Go」「来源：用户明确要求」。字段分隔轻而清楚。
- 从下段右边缘出发一条浅灰箭头，向右进入下方的小便笺。箭头旁标「仅限本次」。便笺标题「当前任务」，内容「回答简短」。便笺视觉上比长期记忆记录更轻。
- 两条箭头分别连接对应原话和输出，没有交叉，不把下段写入长期记忆。无第三条分支、不添加其他模块。
Semantic invariants: 保留项目和示例范围；不泛化为所有任务都用 Go；「这次简短」仅用于当前任务。长期记录保留来源，不宣称来源等于已验证的技术事实。图为假设示例。

Composition: 从左到右阅读，原话左侧，长期记忆右上，当前任务右下。两个输出不重复原话全文，靠范围、默认值与来源的转换体现提取。短直线连接，最多转一次直角。标题位于上方，副注「假设示例」小而清楚。
