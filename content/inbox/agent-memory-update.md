**长期记忆更新依据新旧信息的关系，决定新增、跳过、修改或合并；冲突不明时暂不覆盖。**

[[agent-memory-extraction|提取]]出候选不代表一定新增，可先检索已有条目，再判断关系：

| 关系 | 处理方式 |
| --- | --- |
| 新信息 | 新增 |
| 重复信息 | 跳过，必要时补来源 |
| 同一事实发生变化 | 更新，并按需要保留历史版本 |
| 信息互补 | 合并，保留条件与依据 |
| 暂时无法解释的冲突 | 暂不覆盖，保留待确认状态 |

例如，「主要使用 Go」与「现在主要使用 Python」可能是时间变化，也可能分别描述不同项目。判断须结合明确纠正、来源、时间和适用范围；相似度只帮助找到候选，不能证明矛盾。LLM 可以建议操作，最终写入由程序校验并执行。

更新通常沿用提取触发机制，周期维护补充去重和失效检查；长期积累后的清理策略由[[agent-memory-lifecycle|有效期与遗忘机制]]约束。
