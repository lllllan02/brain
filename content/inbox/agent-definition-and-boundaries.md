**LLM Agent 是以大模型为决策核心、在给定目标下自主决定下一步动作、执行后把结果反馈回决策循环，直到达成目标或主动停止的系统。**

「自主决策」仍受开发者设定的边界约束，例如工具权限、最大迭代次数与终止条件。模型在这些边界内选择下一步动作，[[agent-harness|Harness]] 负责执行约束，也可以在达到限制时结束执行。

这个反馈过程通过 [[agent-loop|最小 Agent Loop]] 实现：模型决策 → 执行工具 → 回传结果 → 再次决策。
