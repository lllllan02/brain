比例份额调度先为任务赋予权重，再让长期获得的 CPU 份额接近权重占比。它关注资源分配，不要求知道任务还要运行多久。

彩票调度把权重变成票数，每次随机选中一张票，所属任务运行。任务 i 的中奖概率为 `w_i / sum(w)`，这描述期望份额；有限次数内实际分配会波动，不能承诺每个短窗口都精确公平。

步长调度用确定性记账减少波动：权重大则 stride 小，每次选择 pass 最小者，运行后给它增加 stride。新任务加入时需要合适的 pass 基线；直接从 0 开始，可能让它追赶历史差额并短期垄断资源。

权重表达的是相对份额，还要决定空闲任务、动态加入和跨组分配如何处理。类似抽样也可用于复习系统：按错误次数、距上次复习时间调整权重，再加冷却约束；这些是业务启发式，不是记忆效果的保证。

CFS 的虚拟运行时间可帮助理解按权重记账，但不能把教材描述直接当成当前 Linux 的完整实现；Linux 从 6.6 开始向 EEVDF 过渡，另外考虑任务资格和虚拟截止时间。[内核说明](https://docs.kernel.org/scheduler/sched-eevdf.html)
