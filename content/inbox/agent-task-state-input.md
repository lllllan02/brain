**在每次相关模型调用前，把当前有效的任务状态加入上下文；独立存储本身不会让模型自动知道其中内容。** 可以将精简状态作为明确标识的文本块随指令和历史一同提供，不要求固定消息角色。

例如，模型输入包含「执行指令 + 最新任务状态 + 历史摘要与近期消息 + 当前用户输入」。这里的状态是[[agent-task-state-detail|关键任务记录]]，不是再复制全部历史；具体格式按[[agent-storage|读写需求]]选择。

更新后用最新版本替换旧版本，避免把多个进度版本都当作当前事实。详细日志、长计划和材料可[[context-loading|保留引用并按需加载]]，核心目标与限制则持续可见。当前用户的新要求也必须提供；它与旧状态不兼容时，按[[agent-task-state-conflicts|冲突规则]]判断，而不能让旧状态压过新指令。
