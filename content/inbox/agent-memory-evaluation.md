**[[long-term-memory|长期记忆]]评测可复用 Agent 的通用效果测评链路，额外关注「跨会话延续、记忆变化和隐蔽的读写过程」。** 过程记录沿用 [[agent-trace-requirements|Agent Trace]]，补充以下检查。

| 记忆特有的检查 | 怎么验证 |
| --- | --- |
| 应记未记 | 会话 A 表达偏好，会话 B 提出需要该偏好的任务；检查是否保存并生效，仅查记忆库发现不了遗漏 |
| 旧记忆失效 | 纠正、删除或到期后开启新会话，检查旧内容是否仍被召回或影响回答 |
| 读写过程不可见 | 在 Trace 中补记提取触发、实际写入、召回与最终注入的记忆 ID、内容和版本，区分没记住、没找到与没用好 |
| 持久状态干扰归因 | 固定初始记忆快照，比较原始、修正和禁用记忆时的任务效果；各次运行隔离写入，避免前一次测试改变后一次的起点 |

**「评测单位要覆盖多次会话及其间的记忆变化」**，只看一次回答或一次检索，无法验证完整的记忆生命周期。
