**反思（Reflection）侧重依据目标与证据判断问题，自我纠正（Self-Correction）侧重据此修改做法并验证效果。** Agent 生成了答案或完成了调用，并不意味着满足任务要求；两者配合，让执行结果能够影响后续行动。

## 两个概念分别指什么？

反思是一种检查与分析过程：结合任务目标、当前产物、执行记录和反馈，判断哪里不符合要求、可能为什么出错，以及应该怎样调整。它的产出是有依据的判断与修改建议；结论也可以是「无需修改」或「证据不足，需要先核实」。错误码、测试失败或用户反馈是反思可以使用的输入，收到这些信号本身不等于已经完成反思。

自我纠正是 Agent 根据已发现的问题修正自身输出或行为的过程：修改参数、答案、行动或计划，再检查问题是否解决。这里的「自我」指由 Agent 承接修正，不要求错误必须由模型自己发现；规则、工具和人工都可以提供依据。提出了修改建议还不等于已经纠正，修改完成也不等于已经修好，仍需验证。

这里按职责区分两者；在具体方法中，Self-Correction 也可能指包含检查、反馈、修改与验证的整个过程。因此，反思可以是自我纠正过程中的一个环节，两者不是必须独立部署的两个模块。

## 这个机制怎样工作？

**取得反馈 → 反思形成判断与建议 → 执行纠正 → 验证结果。** 程序收集错误码、校验结果或测试证据，模型结合上下文判断问题并生成修改；程序再执行必要的调用、计算或测试，把新结果交回检查。规则难以判断时，也可引入模型评估或人工反馈。

假设任务是「查询本月销售额并计算同比」，已有两期同口径数据，但报告只写了本月销售额：

1. 反思：对照任务要求检查报告，指出「缺少同比，已有去年同期数据，可补充计算」。这一步产出明确的问题和修改方向。
2. 纠正：Agent 调用计算工具求出同比，将结果补入报告。这一步实际改变产物。
3. 验证：核对数据口径、计算结果及报告是否满足要求；通过后结束，未通过则依据新反馈继续修正。若去年同期数据实际缺失，应先补查，不能直接编造同比。

**「反思不一定引起修改，纠正也不一定需要单独反思。」** 检查后确认报告已符合要求，可以直接保留；工具若已明确指出日期格式错误，Agent 可以直接按要求修正参数并重新校验。反馈已经足以指导修改时，无需额外安排一次完整分析。

检查与修改可以在同一次模型调用中完成，也可以分为评审和修改两次调用；二者的区别在于承担什么职责，不在于调用次数或是否另设 Agent。它们可以接入执行中的多个位置，不要求固定的「反思阶段」。

具体组织方式可以不同：[[self-refine-summary|Self-Refine]]让同一模型点评并修改当前输出；[[reflexion-summary|Reflexion]]把一次尝试的反馈提炼成经验，供后续尝试使用。Reflexion 是具体方法名，Reflection 是这里讨论的通用反思过程。

如何提供标准与证据、要求可执行反馈，以及验证反思收益，由[[agent-reflection-design|怎样组织有效的 Reflection]]展开；计划审查与结果审查复用这套方法。

## 可以接入哪些环节？

程序在对应入口收集反馈，按需调用这套机制；各入口共享检查与修正逻辑，调整对象不同。

| 接入入口 | 检查什么 | 可能怎样纠正 |
| --- | --- | --- |
| 计划生成后 | 是否覆盖目标、依赖是否合理、执行条件是否具备 | 补齐或调整步骤，核实未知条件 |
| 模型生成后 | 输出能否解析、是否满足格式要求 | 修正结构并重新生成 |
| 工具执行前 | 参数是否合法、调用是否符合约束 | 根据校验反馈修改调用；权限不足不能绕过 |
| 工具返回后 | 错误状态、执行结果与预期是否一致 | 修正参数、换工具或补充信息 |
| 阶段完成或进度停滞时 | 是否取得进展、剩余目标是否清楚 | 补做工作或调整计划 |
| 最终交付前 | 产物是否合格、任务要求是否遗漏 | 修改答案、补齐遗漏并重新验收 |

例如，[[pydantic-retries-summary|Pydantic AI]]可把工具校验错误交给模型修正；普通请求重发则由程序处理。下图与表格的六类入口逐项对应：计划检查返回规划，输出检查返回生成，其余反馈共用返回线交给模型处理。各处按需启用；阶段反思若要求改动剩余步骤，再转入规划。示例中的规划与工具并非必选，前后模型节点表示不同调用轮次。

## 与其他机制怎样配合？

这几种机制的职责与组合关系，见[[agent-feedback-mechanisms|反馈与调整机制]]。

[[agent-retry|重试]]关注再次尝试操作；反思与纠正关注依据反馈改变什么。修改调用后再执行，可以同时包含两者。纠正若改变剩余任务的步骤或策略，就涉及 [[agent-replanning|Replanning]]；重新规划也可由新目标触发，不一定是纠错。

反思不保证有效：[[intrinsic-self-correction-summary|无外部反馈的推理纠正研究]]在其测试条件下发现，模型可能把正确答案改错。因此修正后仍需验证，不必每轮强制反思；重复失败、无进展或达到次数、时间、费用上限时停止或转人工。重做外部操作前，还需检查重复副作用。
