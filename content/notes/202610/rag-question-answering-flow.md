# RAG 是什么，一次问答会经过哪些阶段？

**RAG（检索增强生成）是在回答问题前先检索外部材料，再把材料交给模型作为回答依据**。这些材料可以来自知识库或其他可检索的数据源。

一次常见的问答流程是：

1. **召回**：根据问题检索可能有用的文档片段，得到候选材料。
2. **重排**：对候选材料重新评分排序，优先选取更有助于回答的片段；这是可选的优化环节。
3. **构建上下文**：把选中的正文和来源组织进模型输入。简单拼接或整理成数组就可以完成，不一定需要额外加工。
4. **生成回答**：模型根据问题和证据组织答案，必要时附上引用或说明信息不足。

这里按动作划分流程，实际实现可以合并环节。对于本地知识库，问答前通常还要准备文档、切分片段并建立索引，让召回能够搜索材料。

参考：[Microsoft 对 RAG 与经典问答流程的说明](https://learn.microsoft.com/en-us/azure/search/retrieval-augmented-generation-overview)。
