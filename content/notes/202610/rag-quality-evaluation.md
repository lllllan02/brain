# 如何评估 RAG 的检索与回答质量？

评估 RAG 的检索与回答质量，要沿流程定位问题，重点区分 **没找到、没选中、处理时丢失或失真、拿到证据却答错**。

1. **召回看检索表现**：库中已有的相关证据能否找回，混入了多少无关材料。
2. **重排看排序表现**：更有价值的证据是否靠前，选取前几条时是否保留了应优先使用的材料。
3. **上下文构建看处理损失**：选中的证据在拼接、压缩等处理后，是否被遗漏、改写失真或失去来源。
4. **生成回答看证据使用**：模型是否依据材料作出正确、切题的回答，引用是否支持结论。

> 完整性是共通检查：用同一组必要事实标注，记录候选材料、入选材料、最终上下文分别提供了哪些证据，以及答案正确表达了哪些必要事实。分阶段比较是为了定位缺口出现在哪里，不必在每张卡片重复展开「信息是否齐全」。召回率按片段计数，事实覆盖率按信息项计数，二者不能直接互换。

比较方案时统一知识库、评测样本和评分口径。评估某一阶段的改动时，尽量固定其输入和其他阶段的配置；全流程效果另行比较。证据不足时是否编造、有依据时是否过度拒答，也要单独检查。
