# Agent 评测用例满足什么条件才能入库？

用例入库前要满足**[[agent-failure-replay-cases|可重放]]、可评分、标注有依据且有覆盖价值**，并通过版本管理保证后续比较可信。

1. **判断依据**：审核输入和环境是否能重建目标场景，预期行为是否符合业务规则，评分器是否能识别目标失败；同类用例是否已覆盖该条件。暂时无法重放的案例保留在问题库，待补齐。
2. **做法与工作**：脱敏后复核失败条件没有被改变，按输入和失败机制去重或聚类，保留代表性及必要边界案例；试跑并复核评分。记录用例 ID、来源 Trace、错误类型、标注依据、环境和评分器版本，更新评测集版本。
3. **产出**：带元数据和版本的评测用例。错例回归集用于检查已知问题，代表性流量评测集用于衡量总体质量；保留独立测试集，避免反复调参造成评测过拟合。

业务规则改变时，需要重新审核相关用例及预期行为，不能把已经失效的标准继续作为回归门槛。
