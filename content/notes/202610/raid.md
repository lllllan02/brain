RAID 把多块磁盘组合为一个逻辑存储，用条带分散访问，用镜像或校验保存冗余。可容忍的故障取决于布局与故障位置，冗余不能替代备份。

假设磁盘等容量，每盘容量为 C：

| 布局 | 可用容量 | 故障边界 |
| --- | --- | --- |
| RAID 0：条带 | N × C | 无冗余，任一盘故障都可能破坏阵列数据 |
| RAID 1：双盘镜像 | C | 两盘中容忍一盘故障 |
| RAID 10：双副本镜像再条带 | N × C / 2 | 每组镜像至少保留一盘；两盘故障能否承受取决于分布 |
| RAID 4：独立校验盘 | (N − 1) × C | 容忍一盘故障；校验盘易成写入瓶颈 |
| RAID 5：分布式校验 | (N − 1) × C | 容忍一盘故障；分散校验更新的负载 |

## 校验为什么增加写入成本

一个条带的校验块可以由数据块按位异或得到。一块盘丢失时，用其余块和校验块还原。只更新一个数据块时，可以读取旧数据和旧校验，计算 `新校验 = 旧校验 XOR 旧数据 XOR 新数据`，再写回两块。在无缓存的简化路径中，这是两读两写；全条带写入可以直接计算校验，避免这组旧值读取。

数据与校验在不同盘上更新，掉电可能使它们不一致，即写洞。需要日志、受保护的写缓存或实现提供的其他一致性机制；校验盘存在本身不能保证跨盘更新原子性。

## 为什么重建期间仍可能丢数据

重建会读取大量幸存数据，同时竞争业务 I/O。如果又遇到坏扇区，单校验冗余可能不足以恢复。[[storage-integrity|校验和与后台巡检]] 可以更早发现潜在损坏，但误删、错误覆盖和勒索加密可能同步影响所有副本，仍需独立备份与恢复验证。
