## 范围

本地只读：节点与引用连线、缩放与局部聚焦、节点重点预览、完整正文、搜索、主题筛选和地图入口。按 [[docs/knowledge-management#元数据|元数据约定]] 展示 title，缺省时使用文件名；正文不重复生成标题，摘要缺省取正文开头，未知日期不推断。别名参与检索，类型优先读取 type、兼容已有 classes，来源兼容属性与正文链接。

递归读取 `content/notes/` 的月份目录、`content/maps/` 及引用附件；月份仅用于存放，主题分组读取属性与地图。默认排除 inbox、来源原文、项目说明与配置；本地允许私人内容。公开模式按 [[docs/knowledge-management|管理细则]] 的授权与过滤规则执行。

## 二开约定

- 先核验上游许可证、维护情况、Markdown 与链接支持、图谱交互和扩展方式，用实际文档验证适配，再引入代码并保留必要署名。
- 应用适配文件库，不迁移或复制正文。索引与图谱可重建，布局另存，主题分组与真实引用区分展示。
- 笔记与地图使用唯一英文文件名，内部引用以 Obsidian 双链为标准，解析文件名、显示名、章节、块引用和嵌入；兼容显式路径，无法唯一确定目标时报告歧义。路由与文件位置分开，重命名保留地址映射。
- 读取不突破允许的目录，文档内容不作为可执行代码。

## 验收

修改文件后正文、预览、搜索和图谱同步更新，连线可定位实际引用；英文文件名、中文显示名、双链锚点和附件跳转有效。不同屏幕下正文、代码和表格可读，断链不误跳转。公开构建不包含私人正文、标题、关系、搜索条目或附件。
