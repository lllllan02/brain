# brain 图谱预览看板

预留二开现有项目的空间，当前尚未选定上游项目或初始化应用。项目介绍见 [README](../../README.md)。

## 范围

本地只读：节点与引用连线、缩放与局部聚焦、节点重点预览、完整正文、搜索、主题筛选和地图入口。预览读取正文开头的核心内容，展示状态、更新时间和来源。

读取 `content/notes/`、`content/maps/` 及引用附件。默认排除 inbox、来源原文、项目说明与配置；本地允许私人内容。公开模式按 [管理细则](../../docs/管理细则.md) 的授权与过滤规则执行。

## 二开约定

- 先核验上游许可证、维护情况、Markdown 与链接支持、图谱交互和扩展方式，用实际文档验证适配，再引入代码并保留必要署名。
- 应用适配文件库，不迁移或复制正文。索引与图谱可重建，布局另存，主题分组与真实引用区分展示。
- 处理相对链接、双链及锚点，同名歧义和未知语法明确报告。路由与文件位置分开，重命名保留地址映射。
- 读取不突破允许的目录，文档内容不作为可执行代码。

## 验收

修改文件后正文、预览、搜索和图谱同步更新，连线可定位实际引用；中文与空格路径、锚点、附件跳转有效。不同屏幕下正文、代码和表格可读，断链不误跳转。公开构建不包含私人正文、标题、关系、搜索条目或附件。
