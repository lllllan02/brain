# brain

保存知识、想法、问题、计划和记录的个人大脑。内容以 Markdown 文件保存，Obsidian 与未来图谱看板共享同一份正文。

## 使用与启动

- Obsidian：打开本项目的 `content/`，从 [知识导航](content/maps/知识导航.md) 开始阅读。
- Agent：在 brain 项目中工作，遵守 [AGENTS.md](AGENTS.md)。直接提出「把刚刚讨论的内容整理进知识库」，即可保存并维护链接。
- 图谱看板：`apps/web/` 尚未初始化，当前没有启动命令。后续二开现有项目，以文档节点、引用连线和重点预览作为阅读入口。

## 目录

```text
content/       个人内容：inbox 暂存、notes 正文、maps 导航
apps/web/      图谱看板代码
AGENTS.md      Agent 工作约束
docs/         管理规则的详细展开
```

来源与附件目录按需创建。先用真实笔记验证管理方式，再选择上游项目开发本地看板；具体开发范围见 [看板说明](apps/web/README.md)。
