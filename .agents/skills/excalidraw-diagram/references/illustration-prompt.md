# 知识配图提示词模板

生成位图时使用；矢量绘图也可借此检查设计。先读项目[图文分工](../../../../docs/writing-style.md#图文分工)，查看[认可样图](../assets/diagram-style-reference.png)，从[色板](color-palette.md)选本图需要的颜色。详细风格只在项目规范维护，本模板负责把内容和规范装配成一次可执行请求。

下列占位项按本图填入，保存完整提示词后调用生成工具。风格统一不意味着布局统一：对象、分支、字段、阅读方向与比例按解释目标选择，不默认复刻样图的左右分栏、工具目录或蓝橙职责。

```text
Use case: infographic-diagram.
Asset type: 中文知识笔记中的辅助解释图。
Primary request: {{读者看完应理解的一个关系或机制，以及本图覆盖范围}}。

Reference images:
- {{项目认可样图的实际路径或输入序号}}：仅风格参考。迁移对象造型、轮廓、局部淡彩、文字层级与视觉分量，不复制它的内容或布局。
- {{存在语义参考时填写路径或输入序号；没有则删去}}：仅内容／关系参考，说明必须保留的语义。

Style:
采用项目默认的克制二维技术编辑插画。{{依据当前图文分工规范补入适用于本图的风格要求与避免项}}。
Palette: {{选取的色值，以及每种颜色在本图表达的含义}}。
Aspect: {{由内容与阅读位置决定的比例}}。

Objects and relationships:
{{必须出现的实际对象、必要内部组成、包含关系、连接方向和条件；用具体内容代替空泛的步骤名}}。
Semantic invariants: {{最容易被画错、混淆或遗漏的关系和边界}}。

Composition:
{{适合本图的阅读主线、区域比例、对象变化与连接位置；先确定关系再安排形状}}。
{{说明哪些对象需要简化造型，哪些信息适合文字，哪些内容不在本图范围内}}。

Text, verbatim:
{{逐项列出必须准确呈现的标题、对象名、短标签、字段及必要条件}}。
保持中文清楚、标签贴近对象；不添加未列出的概述段、总结面板或宣传文案。

Validation priorities:
{{本图必须检查的正常路径、分支、方向、归属与状态变化}}。
同时对照风格参考检查形象感、色彩面积、线条与标题分量；输出完整成图。
```

只传风格样图时也须在提示词中独立写清本图的内容与关系；不能让生成器从样图猜测业务。首次使用本地参考图前先查看图片，调用工具时显式传入参考图。位图中文字或关系有误时修正提示词并重新生成；保留候选版本供比较，不通过代码覆盖修补。
